md ファイルで使う記号一覧
================================================================


----------------------------------------------------------------
# 系列（見出し）
----------------------------------------------------------------

  使い方：
    # Purpose        ← 最大見出し・最重要
    ## Risk Pattern  ← 中見出し
    ### 具体例       ← 小見出し

  役割：
    AIに「ここからここまでが xxx の説明だ」と伝える
    文章の構造を理解させる
    Claude・ChatGPT どちらにも有効


----------------------------------------------------------------
@ （本システム独自タグ）
----------------------------------------------------------------

  使い方：
    @skill: transaction_skill
    @agent: transaction_agent
    @tier: 1

  役割：
    このファイルが何者かを宣言する
    現在は人間向けのメモとして機能
    スクリプトは @ タグを読み取らない
    Claude・ChatGPT はどちらも普通のテキストとして読む


----------------------------------------------------------------
- （リスト）
----------------------------------------------------------------

  使い方：
    # Risk Pattern
    - @Transactional の伝播設定ミス
    - ネストトランザクション
    - 長時間トランザクション

  役割：
    「これは並列の項目だ」とAIに伝える
    純テキストより構造を理解しやすい
    Claude・ChatGPT どちらにも有効


----------------------------------------------------------------
| （テーブル）
----------------------------------------------------------------

  使い方：
    | パターン              | レベル | 理由           |
    |---|---|---|
    | 外部API + トランザクション | P1     | ロック保持継続 |

  役割：
    ルールを構造化した形でAIに理解させる
    Severity Rule の定義に特に有効
    Claude・ChatGPT どちらにも有効


----------------------------------------------------------------
``` （コードブロック）
----------------------------------------------------------------

  使い方：
    ```java
    @Transactional
    public void placeOrder() {
        db.save(order);
    }
    ```

  役割：
    「これはコードであり普通のテキストではない」とAIに伝える
    AIがコードとして分析するようになる
    Claude・ChatGPT どちらにも有効


----------------------------------------------------------------
** （太字）
----------------------------------------------------------------

  使い方：
    **最重要：必ず指摘すること**

  役割：
    重要な内容を強調する
    AIが優先的に注目するようになる
    Claude・ChatGPT どちらにも有効


================================================================
Claude vs ChatGPT の使い方の違い
================================================================


----------------------------------------------------------------
基本的に差異はない
----------------------------------------------------------------

  両者ともに純テキストを読む仕組み
  # @ - | ``` ** はどちらも同じように理解する
  特定のAIだけに有効な記号は存在しない


----------------------------------------------------------------
差異がある部分
----------------------------------------------------------------

  項目              Claude                  ChatGPT
  --------------------------------------------------------
  長文の安定性      200K tokens・非常に安定  128K tokens・長文時に品質が下がる場合がある
  構造理解          複雑なmd構造も安定       シンプルな構造は問題なし
  指示の遵守        # 見出しの指示遵守度が高い 基本的に問題なし
  日本語出力        非常に自然              自然
  コード分析        高品質                  高品質


----------------------------------------------------------------
実際の影響
----------------------------------------------------------------

  final_review_prompt.txt が小さい（50KB 以下）
    → Claude も ChatGPT も品質差はほぼない

  final_review_prompt.txt が大きい（100KB 以上）
    → Claude の方が安定する
    → ChatGPT は後半の指示を忘れる場合がある


================================================================
使い分けの推奨
================================================================

  日常レビュー（小〜中規模のコード）
    → Claude・ChatGPT どちらでも問題なし

  重要リリース前（大規模・複雑なコード）
    → Claude を推奨
    → Prompt が大きくなるほど Claude が有利

  Agent Team（複数Stepのレビュー）
    → 各Step の Prompt は小さいため
      Claude・ChatGPT どちらでも問題なし


================================================================
まとめ
================================================================

  記号の意味  ：Claude も ChatGPT も同じ
  品質の差    ：Prompt が大きくなるほど Claude が有利
  @ タグ      ：両者ともに普通のテキストとして読む
  # 見出し    ：両者ともに構造として理解する

  どちらのAIでも動くのが
  このプラットフォームの強み
